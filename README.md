<h1>AgaTool</h1>
AgaTool is a really really cool bookmarklet :D. Originally created for the <a href="https://hackclub.github.io/hacklet/">Hacklet YSWS</a> project and as a way to explore JavaScript development (thats why it's spaghetti code :P), AgaTool lets you do lots of cool stuff :D.

---

## stuff you can do

ok so BASICALLY yeah what you can do with the agatool is uhhhhhhhhhh:
- you can like open a notepad ig
- you can calculate with calculator
- you can search for stuffz (with bing)
- you can view epic websites (so long as they allow iframes (so like barely any))
and the thing that makes it REALLY cool is:
- it SAVES the position, size, AND, contents of windows for each website... so that if your page refreshes just click on the lil bookmarklet again and its back :D isnt that cool :D :D :D :D :D :D :3 :D
- you can open MULTIPLE WINDOWS AT ONCE!!! multitasking is so cool... 😋

## how 2 do the stuff

ok so BASICALLY yeah is you see the lil text box at the top and then you can type this stuff in to do all the stuff above :D
- `notepad`: open teh notepad :D
- `calculator`: open teh calculator :D
- `ai`: open teh ai :D
- `<url>`: open a web address :D
- `search:<query>` search for stuff :D
